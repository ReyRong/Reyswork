Loopable white-noise files live here.

Bundled files should be reviewed, loopable, and licensed for app distribution. See `SOURCE_CANDIDATES.md` for source notes and license checks.

Supported filenames:

- ocean.m4a or ocean.wav
- fireplace.m4a or fireplace.wav
- rain.m4a or rain.wav
- summer-night.m4a or summer-night.wav
- cafe.m4a or cafe.wav
- library.m4a or library.wav

The app handles missing files gracefully if an audio asset is removed.
