Place loopable white-noise files here.

Supported filenames for the first version:

- ocean.m4a or ocean.wav
- fireplace.m4a or fireplace.wav
- rain.m4a or rain.wav
- summer-night.m4a or summer-night.wav
- cafe.m4a or cafe.wav
- library.m4a or library.wav

The app handles missing files gracefully so the prototype can build before final audio assets are added.
