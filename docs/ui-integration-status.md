## 悬停动画修正（2026-11-17）

### 已证实的原因

在同一个现有测试窗口对比展开前后截图，中央时间与音景位置不变，但音量入口纵向位移约 107pt。旧源码用 `if state.isExpanded` 插入整个面板，控件总高度从约 48pt 变成约 260pt，且没有展开/收起动画。此前独立可视探针读数为 0，不用作根因证据。

### 最小修正

- 音量组始终保持 48×260 的占位；面板保留在视图树中，隐藏时禁止点击、禁用子控件并从辅助功能树隐藏。
- 仅随展开状态对透明度、0.96→1 的轻微缩放和入口位置应用临界阻尼弹簧动画（response 0.26、dampingFraction 1）。音量值不参与缓动。
- 用连续悬停位置与自身边界内的有效区域相交判断：收起时仅中心 48pt 为入口，展开或拖动时覆盖整组；高频移动不重复写相同悬停状态。
- 保留 `isDragging` 强制展开与整组键盘焦点逻辑；尊重系统减少动态效果设置。

### 验证与交付

- 纯逻辑探针通过：固定占位、中心入口区域 y=106–154、展开区域覆盖原入口、拖动离开仍展开、外部松手后可收起、无效/过小边界处理。

- 将旋转横向 SwiftUI Slider 替换为 `NSSlider.isVertical = true`；不旋转、不自绘，不改悬停动画或占位尺寸。
- 用 `mouseDown` 进入拖动保护，`defer` 在系统鼠标跟踪结束时退出；即使从 100% 开始、尚未发生数值变化，也会进入保护。
