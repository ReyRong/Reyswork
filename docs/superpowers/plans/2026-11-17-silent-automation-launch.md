# 自动化静默启动接入计划

目标：自动化通过既有 whitenoise URL 启动时不显示窗口和 Dock，手动打开主窗口/设置时显示 Dock。

1. Info.plist 标记后台菜单栏应用，窗口场景禁止默认呈现/恢复；保留最低 macOS 13，现代场景接口按系统版本分支。
2. 自动化控制器在场景初始化时就接入；合法 URL 在控制器就绪前排队，不依赖主窗口 onAppear。无效 URL 不影响窗口决策。
3. 用启动默认性标志区分正常手动启动与资源/URL 启动；手动启动继续尊重已有“打开主界面”偏好，自动化不受该开关影响。显式重新打开 App/菜单栏窗口请求可以恢复主窗口与 Dock。
4. 主窗口和设置统一关闭行为：隐藏窗口而不中断播放；仍有其他可见普通窗口时不隐藏 Dock，最后一个关闭后再隐藏。
5. 补充启动事件先后顺序、手动请求、偏好开关与最后窗口关闭的检查。只做源码类型/语法检查及隔离逻辑探针；未获明确构建指令前不构建、提交或推送。

范围：App 入口、既有窗口行为、设置说明文字、窗口与项目配置测试。音频、URL 路由内容和音景归属不变。
