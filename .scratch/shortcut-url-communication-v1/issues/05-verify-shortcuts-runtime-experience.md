# 05 — 验证快捷指令体验和状态返回

**What to build:** 快捷指令运行体验符合 v1 产品约定：app 未启动时可被唤起执行，执行时不主动弹主窗口，查询状态只返回极简状态。

**Blocked by:** 04 — 收窄 AppIntent 动作并改走 URL Scheme.

**Status:** ready-for-agent

- [ ] app 未启动时，运行“开始助眠”快捷指令可以唤起 app 并开始播放。
- [ ] app 未启动时，运行“助眠白噪音随机”快捷指令可以唤起 app，并从助眠池随机播放。
- [ ] 运行快捷指令时不主动打开主窗口，保持菜单栏工具体验。
- [ ] 查询状态只返回“正在播放”、“已暂停”或“未播放”。
- [ ] 暂停或继续动作在播放、暂停、未播放三种状态下都有明确结果。
- [ ] 手动验证步骤和预期结果已记录。
